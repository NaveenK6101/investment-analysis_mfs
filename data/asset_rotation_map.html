Which asset class is leading, and which is fading

Debt (six large liquid funds), Gold, Silver and Crypto (equal-weight BTC/ETH/SOL/XRP), each compared to Nifty 50 — Indian equity is the reference, so anything in the Leading quadrant is beating equity, and if all four sit in Lagging, equity is the asset class to be in. The x-axis is how strong that trend is right now; the y-axis is whether that strength is accelerating or fading. The trail shows each asset class's path over the last several weeks — where it's been tells you as much as where it is.

Methodology: RS-Ratio and RS-Momentum are an open, transparent approximation of the JdK Relative Rotation Graph methodology (the exact StockCharts/Bloomberg formula is proprietary) — a 10-week rolling z-score of relative strength, then a second 10-week rolling z-score of that. Both are centered on 100: above 100 means stronger/accelerating relative to the asset class's own recent trend, not to zero. This is a read on trend, not a price target.

Each asset class runs from its own start (Debt from 2013, Gold/Silver from the metals history, Crypto from 2020-04 when Solana begins); relative strength is a ratio to Nifty 50, so no common start is needed. This is a level above the Sector Rotation Map and the main leaderboard's other categories: it answers "which asset class," not "which fund or sector within one."
